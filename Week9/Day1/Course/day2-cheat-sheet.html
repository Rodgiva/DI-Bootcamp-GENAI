The 8-week lesson: between May and July 2026 GLM took #1, Kimi K3 shipped at 2.8T, Meta exited open frontier, Qwen split. Don’t memorise the table — learn the six questions below.

What is a weight?

One learned number (like 0.0273) setting how strongly one signal pushes another. “7B” = 7 billion of them. Nobody writes them — training finds them. So: file size = count×bytes; facts are smeared across numbers (no lookup table); quantization just rounds them slightly.

MoE in one paragraph

A Mixture of Experts model has a huge total count but routes each token through a small active slice. Speed & cost follow the small number; download & RAM follow the big one. Almost every 2026 flagship is MoE.

2Picking a model — six questions (the forever-skill)

  1. Task — chat, code, classify, multilingual, reasoning?
  2. License — Apache/MIT (do anything) · Llama (MAU cap) · restrictive (read it)?
  3. Hardware — laptop, single GPU, or cluster? Sets the size.
  4. Latency — interactive or batch? Smaller is faster.
  5. Quality bar — must it beat the frontier, or is good-enough fine?
  6. Hosting — local, your cloud, or a hosted open provider?
Default heuristic

Start with the medium-tier model in any frontier family. Reach for the flagship (or shrink to an SLM) only when a specific task makes you.

Quantization + rule of thumb

Compresses weights (e.g. fp16 → 4-bit “Q4”): ~4× smaller, barely dumber. GGUF quants: Q4_K_M (default), Q5_K_M, Q8_0. 7B at Q4 ≈ 4–5 GB RAM/VRAM.

4The two mini-labs (quick commands)

Pull + run locally
ollama pull qwen3:0.6b      # ~520 MB, any laptop
ollama serve                # API on localhost:11434
Drive it from Python (local, OpenAI dialect)
import requests

def ask(prompt, model="qwen3:0.6b", system=None):
    msgs = ([{"role":"system","content":system}] if system else []) \
         + [{"role":"user","content":prompt}]
    r = requests.post("http://127.0.0.1:11434/v1/chat/completions",
                      json={"model":model,"messages":msgs,"temperature":0,
                            "reasoning_effort":"none"}, timeout=120)  # none = skip thinking
    return r.json()["choices"][0]["message"]["content"]

print(ask("Why consider open-source models?"))

Lab 1 = run the same prompt across three families in the Groq playground (e.g. openai/gpt-oss-120b, qwen/qwen3.8-27b, allam-2-7b) and rank them. Lab 2 = the ladder above, then add a system message → force JSON → hosted provider → swap model="mistral:7b". Four front doors: raw requests, OpenAI SDK, Ollama's own library (think=False, format=schema), LangChain.

5Reasoning models (open-source now too)

Rule

DeepSeek-R1 lineage, Qwen thinking, Llama 4 reasoning variants all think internally before answering. Don’t add “let’s think step by step” — you’ll just pay for duplicate tokens.

Decision shortcut

One agent, one job → OpenAI Agents SDK / Pydantic AI. One agent, a graph of steps → LangGraph. Multiple agents collaborating → CrewAI. Plug into IDEs → MCP. Dropped from old curricula: TaskWeaver, JARVIS.
